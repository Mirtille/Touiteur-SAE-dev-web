## Démarrage local

1. Cloner le projet : `git clone <URL_DEPOT>`
2. Installer l'autoloader : `composer install`
3. Créer la configuration BDD : dupliquer `config.db.ini.dist` vers `config.db.ini` et renseigner les accès.
